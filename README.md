# 🌍 Local Turístico - São Luís

Página web desenvolvida com HTML e CSS apresentando pontos turísticos da cidade de São Luís, com foco em estruturação semântica e organização de layout.

---

## 🚀 Acesse o Projeto
🔗 https://gabrielsants7.github.io/Projeto_Local_Turistico/

---

## 🚀 Tecnologias
- HTML5
- CSS3

---

## 📚 Sobre o Projeto
Este projeto consiste na criação de uma página estática informativa sobre São Luís (MA), destacando:

- Estrutura semântica com HTML
- Organização de conteúdo em seções
- Estilização com CSS
- Uso de imagens e layout visual
- Aplicação de tipografia com Google Fonts

---

## 📍 Conteúdo da Página
- Apresentação da cidade
- Introdução cultural e histórica
- Destaque de 3 pontos turísticos:
  - Centro Histórico
  - Palácio dos Leões
  - Praia do Calhau

---

## 🎯 Objetivo
Praticar conceitos fundamentais de desenvolvimento web, como:

- Estruturação de páginas
- Organização de conteúdo
- Estilização com CSS
- Construção de layouts visuais
